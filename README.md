# Fliegen sind Aliens

Ein 2D-Geschicklichkeitsspiel von Philipp Mallmann fuer GitHub Game Off 2026, gebaut mit Godot 4.7.

Ein Forscher ist sicher: Fliegen sind Aliens. Um es zu beweisen, laesst er sich von ihnen ins All tragen.

Der Code entstand mit KI-Unterstuetzung. `ERKLAERUNG.md` erklaert ihn Zeile fuer Zeile.
